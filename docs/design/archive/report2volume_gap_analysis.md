# Report-to-Volume Gap Analysis

Target task: **radiology report → one or more brain MRI volumes** (report-to-volume generation / text-conditioned 3D medical image synthesis). This is deliberately *not* called "VLM" work here: a vision-language model (as already implemented in `contrastive-pretraining/`, the VL-CABS model) is a *discriminative* alignment model that scores image-text compatibility; the goal here is a *generative* model that produces new volumes from text. The closest existing prior art on this exact dataset is NVIDIA's `NV-Generate-MR-Brain`, a **3D latent diffusion model** (per the MR-RATE root README) — that is the most directly relevant architectural reference point, though 3D GANs, autoregressive latent-token models, and flow-matching models are also viable alternatives (see `recommended_next_steps.md`).

Evidence keys: **[Code]** = repository source; **[Data]** = independently measured from DATA_PATH/SHARDS_PATH in this audit; **[Doc]** = repository documentation; **[Gap]** = absence confirmed by grep/search/read.

## Note on unstratified evaluation (context for the evaluation-plan requirement)

A single unstratified FID (or any single aggregate distributional metric) computed over the whole generated/real population will average across the modality/plane/dtype/orientation heterogeneity documented above and can look acceptable even if the model badly fails on a minority stratum (e.g. MRA, present at only 0.02% of series, or float32-dtype series) — see `mr_rate_local_audit.md` §10 and `recommended_next_steps.md` for the recommended stratified evaluation protocol.
