# Getting an Account -- NHR@FAU HPC Documentation

Source: https://doc.nhr.fau.de/account/

## Overview

The process for obtaining an HPC account at NHR@FAU varies depending on your affiliation.

## BayernKI and NHR Users

Project applicants automatically become managers upon approval. HPC accounts are created by invitation through project managers in the HPC Portal. Contact your project manager to receive an invitation.

## FAU Staff, Students, and Tier3 Basic Service Users

Accounts are created through invitations from department contact persons via the HPC Portal. These accounts are complimentary for publicly funded research and academic theses. Users requiring additional computational resources must apply for an NHR project.

If your FAU institute lacks representation in the portal, you will need to initiate the process for establishing a Tier3 basic supply project first.

## Lecture Courses

Instructors should email hpc-support@fau.de with:
- Course title
- Target system(s)
- Any specialized software needs

A lecture project will then be configured, allowing instructors to distribute account invitations through the portal using official FAU email addresses.

## Block Courses with External Participants

Instructors must submit:
- Course name
- Dates
- Expected participant count

Accounts will only be valid for up to one week.

## After Account Creation

- New accounts become active the following morning (file systems and Slurm databases need updating)
- You must upload at least one public SSH key via the HPC Portal before connecting
- SSH key distribution to all systems takes up to two hours
- User data on HPC systems is deleted three months after account expiration
