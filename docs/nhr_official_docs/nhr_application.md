# Applying for an NHR Project -- NHR@FAU HPC Documentation

Source: https://doc.nhr.fau.de/nhr-application/

## Scientific Offerings

NHR@FAU specializes in performance optimization and atomistic simulations, including molecular dynamics, chemistry, and material sciences. The center has particular expertise with Gromacs, Amber, and VASP applications.

## Available Compute Resources

Two cluster types serve NHR projects:

**GPU Clusters:**
- **Alex**: NVIDIA A100 (40/80 GB) and A40 (48 GB) GPGPUs
- **Helma**: NVIDIA H100 (94 GB) and H200 (141 GB) GPGPUs

**CPU Cluster:**
- **Fritz**: Intel Ice Lake (2x36 cores, 256 GB RAM) and Sapphire Rapids (2x52 cores, 1-2 TB RAM)

## NHR Project Types

| Type | GPU Hours (Annual) | Core Hours (Annual) | Review | Notes |
|------|-------------------|-------------------|--------|-------|
| Test/Porting (3-4 months) | up to 3,000 | up to 500,000 | Technical | Rolling call; unavailable to FAU members |
| Starter (up to 12 months) | up to 10,000 | up to 1,000,000 | Technical | Rolling call; once per group |
| Normal Pre-reviewed | 6,000-60,000 | 1-30M | Technical + simplified scientific | Rolling call |
| Normal Non-pre-reviewed | 6,000-60,000 | 1-30M | Technical + two external reviews | Rolling call |
| Large | 60,000-180,000 | 30-100M | Technical + two external reviews | Deadlines: Jan/Apr/Jul/Oct 1st |
| Follow-up | As above | As above | Technical + external review | Requires intermediate report |

Review typically takes under 3 months; test projects require 3-4 weeks. Standard runtime is 12 months; pre-reviewed projects may extend to 3 years.

## Application Process

Submit applications through [JARDS](https://jards.nhr-verein.de/), along with supplemental information using the official template (saved as single PDF).

## Project Completion

Upon project conclusion, submit a report using the provided template from your university email account to hpc-support@fau.de.

## Acknowledgment Requirements

Acknowledge NHR@FAU support in publications and send copies to nhr-redaktion@lists.fau.de to support future center funding evaluation.

Required acknowledgment text for NHR projects:
> "The authors gratefully acknowledge the scientific support and HPC resources provided by the Erlangen National High Performance Computing Center (NHR@FAU) of the Friedrich-Alexander-Universitat Erlangen-Nurnberg (FAU) under the NHR project **<Your NHR@FAU project ID>**. NHR funding is provided by federal and Bavarian state authorities."
